# node-react-redux-webpack

This is a simple project starter based on **nodejs** as a server, **webpack** as a project builder and **reactjs + redux** for the front-end. I am using **SCSS** for the style. Bu, you can also use css.

Before starting the project make sure that you have [nodejs](https://nodejs.org/en/) and [mongoDB](https://www.mongodb.com/) installed.

# Installetion

1. Pull the project to your computer:

   `` git pull https://github.com/denish12/node-react-redux-webpack.git ``

2. Install  webpack:
   `` npm install webpack -g ``
   
3. Install all dependencies:
   `` npm install ``
   
# Run project

1. Run mongo server:
   `` mongod ``
 
2. Run node dev server: 
   `` npm run dev `` or `` npm run dev:win `` for windows
   
# Other commands

1. Build for production `` npm run build``
2. Build front-end only for production `` npm run build:front ``
3. Build back-end only for production `` npm run build:back ``
4. Run production `` npm start ``
